## 运行方式

在具有训练开发依赖的 Python 环境中，TRAIN_MJ_ROOT 指向训练 Git 仓库：

```powershell
python -m rilab.cli parity-check --config configs/parity.yaml --output-dir outputs/parity_recheck
```

各 profile 的 tag+commit 固定在配置登记中；源码只读导出后在独立进程运行。对默认冻结 tag，预期两个 profile 都因 DEF-001 返回 FAIL，命令退出 1；普通 XML 和 HTTP 检查的结果分别保留，不掩盖边界失败。

验证已修复的新分支：

```powershell
python scripts/check_xml_parity.py --source-root outputs/train_mj_def001 --fixtures-root "$env:TRAIN_MJ_ROOT/tests/fixtures/tenhou" --profile full_state_v2 --output-dir outputs/parity_fixed_recheck
```

单独导出席位可见 MJAI：

```powershell
python scripts/tenhou_xml_to_mjai.py --source-root outputs/train_mj_def001 --input <Tenhou.xml> --seat 0 --output outputs/seat0.jsonl
```
