# v1.3.0 阶段收尾里程碑

日期：2026-11-05。仓库：riichi_lab。附注 tag：`milestone-v1.3.0-online-evaluation`。

本里程碑封存 v1.2.0/v1.3.0 的接入、对局、评估与线上实绩分析，作为后续接入 v1.4.0 的起点。该 tag 标识适配/评估项目的阶段成果，不新建或改写 train_mj 的模型版本 tag，不代表确认 v1.3.0 在所有对手环境中更强。

## 已完成范围

- A0–A3：固定依赖与夹具、两个版本的后端注入和独立席位适配、动作绑定、自动席位编排、运行产物与故障处理。A2 对原冻结模型保留已解释的 DEF-001 例外，不伪造为严格对拍全绿。
- A4：128 个独立种子、1,792 半庄的预登记实验完成，1,102,487 次决策离线回放通过。正式门槛结论为证据不足；观测平均顺位改善约 0.0703。
- B0/B1：协议模拟与真实平台验证已有验收记录。B2 有界排位工具及故障停止逻辑可用；保留远端 d73e2be 的修复：总批次时间仅限制开启新局，已进入的当前局保留独立会话时限，结束后停止开新局。
- 线上评估：云端只读提取 581 份会话、575 份终局记录，保留缺失与不完整结果；核对用户截图，并分开报告线上和固定旧版对手的本地结果。
- 评分报告：将观测收益、方向证据、实际收益门槛和末位率约束分开展示；增加线性顺位得分、时间/席位敏感性分析和文件/参数双重身份核验。
- 193 项测试曾在隔离副本通过；本次保留远端最新修复后，在恢复的实际工作区复验为 **201 passed**，Ruff 检查通过。新增的测试覆盖批次时间不截断当前局等远端回归用例。

## 当前结论与边界

用户截图中，v1.3.0 平均名次 2.39，v1.2.0 为 2.57；云端可核实终局也同向，顺位改善范围为 0.1609–0.1748。按共同时间/席位调整后，观测收益约 0.11，但区间仍宽。结论是 v1.3.0 在本次线上环境中观测领先，不将其直接外推为所有对手环境的普遍提升。

云端 final.inference.pt 与 A4 的 v1.3.0 checkpoint 参数张量指纹一致，文件哈希变化来自训练信息/优化器等封装差异。当前文件核验不冒充历史进程内存鉴证。原 A4 正式门槛与结论保持原样，线上观察性数据没有事后混入该实验。

DEF-001 的采样器修复已有独立分支；旧 tag、已有数据和权重不会因此自动修复。此里程碑不启动训练、不改线上部署，不自动追加实验样本。

## 下次接入 v1.4.0

1. 先读取新版本实际模型元信息，登记 tag/commit、feature_schema、turn/response 维度、候选上限、权重文件 SHA256、参数指纹和有效校准。不要仅替换显示版本号或绕过 revision/profile 校验。
2. 输入语义与既有 profile 相同时，可在明确登记新 revision 后复用投影；布局或语义变化时新增 profile/适配，并重跑契约与 parity 检查。
3. 保留本里程碑作为回归基线，先运行动作/协议/映射测试及短联调，再运行批量工程验收。遇到已知例外仍需明确披露，不能静默降级。
4. 强度实验先定义目标对手环境、固定基线与部署策略，再封存预算、门槛和独立种子。工程种子 1–8、已用正式种子 10001–10128 不重新算作新的独立验收样本。
5. 若目标是线上表现，记录权威比赛 ID、时间、席位、对手身份/评级、实际动作、fallback/defaulted 和模型身份；当前协议缺失的信息应显式保留为未知。
