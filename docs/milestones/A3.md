# A3 工程稳定验收

2026-11-03。**A3 已实现并验收通过。** DEF-001 按用户确认作为已知例外记录，不影响本阶段推进；冻结 tag 和既有权重不变，不启动训练。

## 实现

- `scheduling.py` 按种子和配置顺序展开日程。cyclic4 同步移动后端和焦点身份；四同版本控制局保留四条记录；unique6 枚举六种 2v2 组合。主配对组必须有两个焦点对齐、对手一致的 matchup，拒绝空/重复种子及缺失统计协议。
- `batch.py` 按日程执行完整半庄，两套独立 HTTP 实例复用连接，四席 agent/tracker/立直计划各自独立。启动分别预热 turn/response，每局结束及批量结束复查元信息，禁止热更。
- `artifacts.py` 校验落盘结果与日程完全对应，拒绝缺局、多局、失败局、fallback 和事件摘要不一致。任何故障停止开启新局、标记整次运行无效并非零退出；完成局和错误局产物保留，不过滤错误后作结论。
- 日志同步写入（排队容量为 0，以磁盘写入形成背压），每局为独立 gzip 分片。首次验收配置 full_snapshots_first_run=true，整轮保留所有完整输入；后续大批量可显式设为 false，每 100 次决策保留完整快照；每次仍保留事件增量、候选与原始动作绑定、模型预测和实际动作、耗时。运行期间另有完整决策暂存，成功后删除，失败时保留；默认总容量上限 2 GB，另对当前局施加保守未压缩字节上限。
- manifest 保存完整配置和日程、本仓库 commit/dirty、Python/依赖、完整规则布尔项、每实例元信息及校准、预期权重哈希。HTTP 不证明权重文件哈希，真实验收启动脚本从训练 tag 导出干净源码并实际校验四份 checkpoint，再保存部署证据。
- 相同初始 seed 仅保证配对边界；鸣牌/杠等行为分叉后不承诺共同未来牌山。引擎未提供独立牌山标识，manifest 明确记录 null。

## 运行

已部署两个服务时：

```powershell
.venv/Scripts/python.exe -m rilab.cli arena-selfplay --config configs/arena_selfplay.yaml --output-dir outputs/arena/my_run
```

使用训练开发 Python 启动隔离的真实双服务，自动校验 tag/权重并完整运行两次（只读使用训练代码与 checkpoint）：

```powershell
python scripts/run_a1_integration.py --train-mj-root ../train_mj --output-dir outputs/a3_acceptance_20261103 --batch
```

配置种子 1–8，每个种子 4 个候选局、4 个基线控制局、6 个 2v2 局，单轮共 112 半庄。脚本分别在 batch/ 和 replay/ 输出完整日程。单局手工 `--seed/--seats` 仍可使用；不传这两个参数时执行配置日程。

重跑比较全部逐局席位/焦点/配对键、分数、顺位、步数、决策数、事件摘要及决策摘要。决策摘要覆盖全部输入快照、事件、候选绑定、模型选中动作与原始引擎动作；耗时、模型预测中的部署路径和 gzip 文件头不属于确定性比较项。仅比较终局分数不足以通过重跑检查。
