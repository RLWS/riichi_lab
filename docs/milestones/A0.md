## 偏差与发现记录

1. **`rilab/backends/base.py` 为方案 §10 模块清单之外的补充**：后端抽象（`PredictBackend`）供 A1 实现 http 后端复用；不引入新功能，属实现细节，随 A1 一并实现。
2. **response `candidate_limit=16`**（turn=64）：比方案 §5 假设更紧的硬约束，候选绑定超限失败逻辑按 16 实现（compatibility.md §1）。
3. **PyO3 枚举陷阱**：`ActionType` 无 `.name`，`str()` 返回大写变体（`DISCARD`）；已在采集脚本建立 CamelCase 映射，A1 tracker/mapping 实现沿用。
4. **采集策略修正记录**：初版全席位贪心鸣牌导致 100% 流局；改为分席定向（0-2 立直追求者 + 3 贪心鸣牌位）后边界命中恢复正常。该脚本保留为夹具再生入口，策略本身属于一次性采集工具，不进入生产依赖。
5. **夹具体积治理**：原始 JSON 85MB → 紧凑 JSON + gzip 1.4MB（方案 §7 日志治理原则提前应用于夹具）。
