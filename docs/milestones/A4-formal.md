## 事先登记的规则

使用 10,000 次 paired seed-cluster percentile bootstrap，随机数种子 20261103，95% 区间。所有差值为候选减基线。

1. 有意义提升：平均顺位差的区间上界 ≤ −0.05，**并且**末位率差的区间上界 ≤ +0.02。
2. 有意义回退：平均顺位差的区间下界 ≥ +0.05。
3. 其余：证据不足。辅助指标和 2v2 不替代主实验规则。

事件率分母是各组焦点席位参与的手数，包含中途流局；因对局进程分叉，两组手数可以不同。双响分别记各赢家，但同一放铳者在该手只记一次。各辅助区间为描述性边际区间，不能据其单独下升级结论。

**末位率约束通过**：区间上界 +1.7578 个百分点小于登记的 +2 个百分点。**顺位收益门槛未通过**：其区间上界 +0.0293 未达到 ≤ −0.05，且区间跨零；也未触发有意义回退门槛。因此正式结论是 **insufficient_evidence（证据不足）**。

候选观测平均顺位和末位率较好，但本轮不能排除抽样波动，不能确认至少 0.05 的顺位收益。和率与副露率更高的同时放铳率也更高，这些仅提供后续诊断方向。两版本实际校准不同，因此比较的是完整部署策略，不能单独归因于特征或网络结构；DEF-001 继续作为已知训练侧例外披露，本实验没有证明它的棋力影响可忽略。
