## 实现与口径

`rilab/evaluation.py` 消费 A3 manifest、summary、逐局结果和 MJAI 事件。先核对配置展开的完整日程，再调用 A3 产物审计；缺局、额外局、无效运行、fallback、事件/完整决策摘要或 summary 不一致均拒绝生成报告。不从一个无效运行里过滤出“成功局”继续分析。

主实验使用 candidate_vs_baseline 与 baseline_control 同一 `(paired_group, seed, rotation)` 的焦点席位。每个种子的四次轮换及两组数据构成一个簇，bootstrap 联合有放回抽取整个种子簇。候选减基线的平均顺位差低为好；末位率另列。2v2 六种组合单独汇总，同桌两份候选不算队友，同桌四席也不算四个独立样本。

| 指标 | 分子 / 分母 |
|---|---|
| 平均顺位 | 引擎给出的最终顺位之和 / 焦点半庄数；2v2 为各后端席位半庄数 |
| 末位率 | 最终顺位为 4 的席位半庄数 / 席位半庄数 |
| 平均终局点数 | 最终整数点数之和 / 席位半庄数 |
| 和率 | 玩家和牌的手数 / 该玩家参与的手数 |
| 放铳率 | 玩家作为荣和付款方的手数 / 该玩家参与的手数 |
| 立直率 | 已接受立直的手数 / 参与手数；reach 宣言率另列，宣言弃牌被荣和不算已接受 |
| 副露率 | 至少一次 chi/pon/daiminkan 的手数 / 参与手数；同手多次副露只计一次，单独暗杠不算副露 |

“手数”按 start_kyoku 计，含中途流局；双响分别给两个赢家各记一次和牌，放铳者在该手只记一次放铳，自摸不算其他三家放铳。加杠不额外增加已发生的碰牌手数。并列点数不自行重排，沿用引擎最终顺位。振听率未作为强度指标。

每个指标保留分子与分母。顺位按席位半庄平均；各事件率使用总体分子/总体分母，bootstrap 每次抽样后重新计算比例，不能对不同手数种子的比率简单平均。默认 10,000 次重采样、随机种子 20261103，95% percentile 区间采用 `(n-1)*p` 线性插值。各辅助区间是描述性边际区间，不是多指标同时检验后的晋级规则。

report.json 保存每种子计数、焦点观察、指标、补充实验、模型/权重/校准元信息、源 manifest/summary 哈希、分析 Python 版本及统计模块 SHA256。report.md 提供简报。默认只允许生成 exploratory 报告，strength_verdict 固定经过探索性资格门槛返回 insufficient_evidence；退出码 0 表示报告生成成功，不表示版本胜出。

## 工具验收结果

- **84 项测试通过**，其中 18 项 A4 用例覆盖已知 bootstrap 分布、配对相关性、联合重采样、比例分母、双响、重复副露、未接受立直、缺失日程和无效源数据等。Ruff 检查通过。
- 使用 A3 正式第一轮的 112 半庄：主实验 32 候选焦点局 + 32 控制焦点局，补充 48 个 2v2 局，**独立统计簇只有 8 个种子**。
- 对 A3 完整重跑产物独立执行同一分析，全部主/补充指标、每种子计数和焦点观察完全一致。两份重跑报告绝不合并成 16 个独立种子或 224 个独立新对局。
- 证据：[A4.json](evidence/A4.json)。本地完整报告位于 outputs/a4_tools_final_20261103/batch/ 和 replay/。

| 探索性主指标 | 候选 v1.3.0 | 基线 v1.2.0 | 候选减基线 | 95% 簇 bootstrap 区间 |
|---|---|---|---|---|
| 平均顺位 | 2.4375（78/32） | 2.5（80/32） | −0.0625 | [−0.1875, 0.09375] |
| 末位率 | 18.75%（6/32） | 25%（8/32） | −6.25 个百分点 | [−18.75, 6.25] 个百分点 |

**结论：证据不足。** 两项主指标区间均跨零；这批种子原本用于工程验收，结果已被观察，不能事后称为预注册强度实验。两版本服务端校准也不同，当前比较对象是完整部署策略，不能将差异单独归因于网络结构、权重或特征。DEF-001 保留为已知例外，现有数据不证明其棋力影响可忽略。

## 使用

```powershell
.venv/Scripts/python.exe -m rilab.cli arena-evaluate --run-dir outputs/a3_acceptance_20261103/batch --output-dir outputs/my_exploratory_report
```

可选 `--iterations` 与 `--bootstrap-seed` 调整计算预算和随机数种子；这不增加实际独立对局样本量。输出目录必须不存在。原始大体积事件/决策日志留在 outputs，Git 仅包含代码、测试、文档和汇总证据。
