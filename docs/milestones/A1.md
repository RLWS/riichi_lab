# A1 最小闭环 — 实现与验收

2026-11-02。已完成后端注入、每席状态/动作适配、两个版本投影及手工四席单局；A2 完整 parity 仍是后续闸门，不能把本阶段结果当作强度提升证据。

## 交付

- StateTracker 只消费本席 Observation 增量，只保存自家精确手牌与公开信息；手牌、点数和宝牌与引擎实时交叉检查。跨局重置，立直待接受/已接受分离，杠窗口保留前态；异常立即退出。
- DecisionContext 按合法动作阶段区分 turn/response。CandidateBinding 保留原始引擎 Action；精确牌、consumed、来源完整映射；模型结果严格回查；立直计划在后续弃牌窗口执行，不重新调用模型。
- LegacyV12Adapter / FullStateV2Adapter 分别投影。旧版保留 tag 中的历史输入：百点单位、弃牌数近似巡目、静态供托及显式 dora_base_indices；新版维持完整 state 及实际摸牌次数。它们是训练特征口径差异，不改变引擎规则。
- HttpPredictBackend 与 BackendRegistry 独立连接/校验各服务，按 profile 验证维度/schema；每次结果模型信息必须与启动基线一致，候选超限失败；null 与显式 0 校准分别保留。两个头使用隔离的真实初始窗口预热。
- MjaiBotAgent 注入 backend 与 adapter；四席 tracker/立直计划隔离。执行确认后才提交放弃合法荣和的振听标记；拒绝不提交。在线 ack 仍由未来 B0 session 负责。
- 单局 runner 输出 manifest、完整决策 JSONL、MJAI 和 summary，保留失败产物并抛出错误。manifest 区分各后端实例、预期权重哈希和服务元信息；HTTP 本身无法证明远端文件哈希，部署验证脚本另行核对。

## 实测证据

固定 seed=1，GameRule.default_tenhou，四席为 [v1_3_0,v1_2_0,v1_2_0,v1_2_0]，CPU 上运行两个独立的真实 HTTP 服务。两个源码 tag 从训练仓库只读导出到 outputs，两个进程分别 import 对应 mjai；四份权重按配置 SHA256 验证，未修改训练仓库或切换其分支。

最终修正旧版宝牌和供托口径后的结果：

- 629 个引擎 step、634 个决策；合法执行至 end_game，状态断言无失败。
- 正式对局推理：新版 153、旧版 467；每实例另有 2 次预热，单独计数。
- 两版本均覆盖 turn 与 response；14 次 reach、13 次 reach_accepted、14 次计划弃牌，包含宣言未接受即终局的场景；8 次碰、2 次吃。
- 点数 [25100,69100,-4800,10600]，顺位 [2,1,4,3]。这只证明接入可运行，不作两个版本强度结论。
- 现有 60 场黄金夹具的 45,720 个决策事件均经 tracker 回放；3,209 个保存的 Observation 校验状态与候选绑定。另以定向夹具验证抢杠前态。
- 两个 profile 分别与固定版本训练快照构建器做引擎事件 smoke 对拍：每个 profile 比较 13,084 个状态、456 个编码向量，无差异。范围不包含 XML 转换、候选编码及放弃和牌解析，不能替代完整 A2。

汇总证据见 [A1.json](evidence/A1.json)。完整本地产物位于 outputs/a1_dual_http_final_seed1，outputs 不入 git。

## 使用方式

两个服务按配置独立部署后，在本仓库运行：

```powershell
uv run rilab arena-selfplay --config configs/arena_selfplay.yaml --seed 1 --seats v1_3_0,v1_2_0,v1_2_0,v1_2_0 --output-dir outputs/manual_seed1
```

输出目录必须不存在，避免覆盖已有证据。缺少显式 seed/seats/output-dir 会非零退出；matchups 的自动轮换属于 A3，当前不会擅自批量运行。

复现真实双 HTTP 联调：在有 torch、FastAPI、uvicorn、httpx、PyYAML 的训练开发 Python 环境运行：

```powershell
python scripts/run_a1_integration.py --train-mj-root $env:TRAIN_MJ_ROOT --output-dir outputs/a1_recheck --seed 1
```

该脚本使用本仓库 .venv/Scripts/python.exe 运行客户端，临时服务仅监听 loopback，完成或失败后均终止。要求本地 tag/commit 与配置一致，权重文件存在且哈希匹配。

引擎事件 profile smoke 使用上述导出的固定版本源码分别运行：

```powershell
python scripts/check_profile_oracle.py --source-root outputs/a1_recheck/v1_2_0 --profile legacy_v1_2 --output outputs/oracle_old.json
python scripts/check_profile_oracle.py --source-root outputs/a1_recheck/v1_3_0 --profile full_state_v2 --output outputs/oracle_new.json
```
