# 线上实绩与版本评分改进

2026-11-05。**本次线上观测明确由 v1.3.0 领先。** 截图平均名次改善约 0.179，云端可核实终局的改善范围约 0.161–0.175。此前 A4 的本地观测也偏向 v1.3.0，但置信区间尚未达到登记的推广条件；不能把该门槛结果概括成“两版本没有差距”。

## 数据与读取边界

用户提供了两张平台“全部时间”统计截图，并授权只读访问云端。读取只使用 SSH、文件读取及低优先级 CPU 参数指纹计算，未改部署配置、启动训练、重启或停止服务。读取前后两台推理服务 PID 均保持为 5993、6274；SSH 已退出。

云端读到 9 个批次、581 份会话日志，其中 575 局有终局分数；另 1 份会话目录缺少日志。未完成记录也保留在报告：v1.2.0 有 2 份已观察到开局但无终局、2 份未观察到开局；v1.3.0 有 2 份已开局但无终局。没有把失败批次中已完成的真实对局静默删除，也没有给未知结果补一个胜负。

云端可核实终局为 v1.2.0 的 281 局与 v1.3.0 的 294 局，未与截图的 294/334 局完全对齐。截图没有准确时间范围或比赛 ID，不能把它与云端记录相加，也不能声称已经拿到截图全部 628 局的逐局明细。

### 同时段、同席位敏感性分析

新增比较以“UTC 日志完成小时 + 初始席位”分层，仅在两版本都有观测的格子中比较，使用 min(两组局数) 的重叠权重，再按整个小时重采样。共 14 个小时簇、52 个共同格子，涵盖新版 294 局、旧版 277 局；其余 4 局旧版没有共同支持，仍保留在总体描述中。

调整后的候选减基线平均名次差范围为 [−0.1219, −0.1055]，同分边界加小时簇 bootstrap 的保守 95% 区间为 [−0.3668, 0.1246]。这项分析说明：控制部分样本构成后，观测领先仍在，但幅度缩小、统计不确定性较大。不能把数百局直接当作彼此独立的数百次实验。

小时来自日志落盘时间，包含排队及持久化时间误差；旧协议未记录对手 ID、评级和权威比赛 ID，所以尚不能校正对手强度、准确识别跨账号同桌，或完整隔离账号匹配机制的影响。时间/席位调整是观察性敏感性分析，不冒充随机对照实验。

## 文件哈希疑点与参数等价核验

云端 v1.3.0 的两个任务都读取 final.inference.pt，文件 SHA256 为 7e6ed0b8aa6161ecc0a0699f8a7f701393d9cce81ec31b65a5f239b261654e99；与 A4 登记的 best_turn.pt / best_response.pt 文件哈希不同。

仅凭这个差异不能认定模型参数换了。实际使用 weights_only=True、CPU 单线程只读加载后，对排序参数名、dtype、shape 及连续原始参数字节计算指纹：

- 云端 final.inference.pt、本地 best_turn.pt、本地 best_response.pt 的完整参数指纹均为 be90a2938417ed9bd4f2b1345625804187d7de06d28fa4eec30e8b4b79d67431。
- turn 和 response 的任务参数指纹也分别一致，checkpoint 去掉了 optimizer_state_dict 等训练信息。
- 两个训练代码仓库 HEAD 与登记的 v1.2.0/v1.3.0 commit 一致；服务记录的 schema、维度和有效校准符合原部署。v1.2.0 的文件 SHA256 本身也一致。

因此，本次观测到的文件差异属于推理包封装差异，不能拿它解释为模型训练参数变化。新工具同时保留文件身份和参数身份；参数检查限定为当前文件与 A4 固定文件的等价性，不伪称获得了历史进程内存中的参数鉴证。云端模型和配置没有被替换。

## 代码改进

1. `rilab/scoring.py` 将观测收益、方向证据、最小有意义收益门槛、末位率约束分别输出。保留原 A4 正式判定，不把“门槛未通过”显示成“没有收益”。
2. 增加透明的 0–100 顺位得分：100×(4−平均顺位)/3，一位=100、四位=0。截图旧版 47.62、新版 53.59，领先 5.97 分。这仅线性换算同一份顺位数据，不新增证据，也不是平台评分或跨对手池通用实力值。
3. `rilab/ranked_evaluation.py` 增加线上快照、截图、覆盖差异、未知同分、未完成结果和时间/席位敏感性分析；不同对手环境分别报告，保持不相加、不暗中筛选。
4. `rilab/ranked_snapshot.py` 与 `scripts/read_ranked_snapshot.py` 只读导出需要的结果、部署和审计字段；不导出 token、手牌或完整模型输入。SSH 密码交互输入，不保存到脚本或报告。
5. `scripts/fingerprint_checkpoint.py` 检查模型参数身份，避免把去优化器、重新保存等封装差异误判成模型变化。

完整验证为 **193 项测试通过**，在隔离的临时 Git 副本中执行；原工作区暂存状态保留。新用例覆盖舍入计数、分层混杂、无共同支持、失败批次、缺失结果、同分边界、参数得分方向、收益与门槛分离，以及敏感字段不被导出。
